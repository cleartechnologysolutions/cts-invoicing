CLEAR TECHNOLOGY SOLUTIONS INVOICING — BUSINESS EXPENSES UPDATE (1.4.0)

EXISTING INSTALLATION — APPLY THE NEW TABLE BEFORE DEPLOYING
1. Download a full backup from your existing app.
2. In Cloudflare, open your EXISTING D1 database and its Console.
   Paste the contents of UPDATE-BUSINESS-EXPENSES.sql and run it.
   It adds only the expenses table and is safe to rerun. Existing data stays intact.
   CLI alternative, from this extracted folder with Wrangler authenticated:
   npx wrangler d1 execute DB --remote --config wrangler.jsonc --file UPDATE-BUSINESS-EXPENSES.sql
3. If you have NOT installed Time Entries, also run UPDATE-TIME-ENTRIES.sql.
   Do not rerun the original table creation SQL against an existing database.
4. Upload this ZIP's extracted contents to your GitHub repository root.
   Keep your existing wrangler.jsonc if your Worker or bucket names differ.
   Supplied D1 ID: 5cb39212-e308-4ca9-b09e-0e8f154c64ae.
5. Cloudflare build command: blank. Deploy command:
   npx wrangler deploy --config wrangler.jsonc
   Preserve ADMIN_PASSWORD, DB and BUCKET bindings. No new bucket is needed.
6. Refresh the app and select Business Expenses.

BUSINESS EXPENSES
- Record date, vendor, business purpose, category, total paid (including tax), notes.
- Optionally select a client; this is non-billable and never adds to their invoice.
- Attach a photo, screenshot or PDF; drag/drop or paste an image into the receipt area.
- PNG, JPEG, WebP and PDF supported, up to 5 MB each.
- Filter by year or custom dates, client and category. Export the filtered list as CSV.
- Category totals summarize spending, not calculated tax deductions.
- Archive removes an item from active totals. Select Archived expenses to restore it.
- Use Purchases for resale products; those are excluded from Business Expense totals.
- Full backups include expenses and all receipt files. CSV contains the list, not image files.
- New backups are version 3; restoring older version 1 and 2 backups is still supported.

TIME ENTRIES / INVOICING
- Start/end times calculate hours rounded up to 15 minutes. Clock times stay internal.
- Rates fill from the selected customer's billing category.
- Select unbilled entries by checkbox; saving a draft reserves them and finalizing closes them.
- Timesheets reports support 48 hours, 7 days, 30 days and custom dates.
- Existing finalized invoices are unchanged.

NEW INSTALLATION
Create D1 and set its ID in wrangler.jsonc. Create private R2 bucket cts-invoicing-receipts.
Apply migrations in order:
npx wrangler d1 migrations apply DB --remote --config wrangler.jsonc
Set ADMIN_PASSWORD runtime secret to at least 12 characters, then deploy as above.
